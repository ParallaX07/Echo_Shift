Echo Shift is a single-player, top-down, turn-based puzzle game. You play a
technician escaping six dark, under-powered chambers by recording a short
sequence of moves and replaying it as an **echo**, a ghost copy of yourself
that walks the recorded route while you take a different one. This is the first
release, with ready-to-run builds for Windows, macOS and Linux.

## What is in this release

### Engine

- A headless rules engine with no Pyxel dependency, so every rule is tested
  without a window.
- Immutable, deterministic state: the same chamber and inputs always give the
  same result.
- One turn-resolution function with a fixed order: expire the echo and refresh
  pads, apply power changes, move the player and the echo, update pads and
  timers, then check safety and the exit.
- Data-driven chambers in JSON, validated on load (links, positions, unique
  ids, circuit capacity, turn limits).

### Echo recording and replay

- Record up to 12 moves and waits, save the take, then launch the echo from the
  hub. The echo ignores darkness, can overlap you, and is blocked by closed
  gates.
- Retry restores the launch snapshot with the same recording, restart clears
  power and recording, and undo steps back one accepted input as often as you
  like. Mistakes such as walking into a wall cost nothing.
- Preview any turn of the saved recording before you launch it.

### Power and lighting

- A generator capacity is a simultaneous limit: any set of circuits whose loads
  fit can be on together, and an over-budget setting is refused.
- Circuits light zones and run gates and elevators. Ending a turn on an unlit
  tile fails the attempt.
- Pads are active while occupied, and timed pads keep a countdown after you
  step off. Gates and elevators need both power and an active linked pad.

### Energy cells, free roam and live conduits

- Energy cells raise your maximum power. You take them by walking onto them in
  free roam, before a take and after one is saved.
- Free roam over lit tiles costs no turns and the world does not react.
- Live conduits are floor that is deadly to you while their circuit is powered.
  Your echo is immune to them.
- Log terminals in the hub rooms can be read for free.

### The six chambers and solver-checked goals

- Six chambers, each teaching one idea: safe movement, power allocation,
  recording, replay in darkness, timed pads and a final escape that combines
  them.
- Each chamber has optional goals (a turn count and a recording length)
  computed by an exhaustive solver, so every goal is reachable. The result card
  and the chamber select show which you met.
- Every chamber has a recorded solution that is replayed by the test suite.

### UI, panels and controls

- Full keyboard play, full mouse play (tile clicks, bar buttons, right-click to
  close) and full gamepad play.
- Guided lessons with a **Next step** line and a highlighted target, free play,
  and hover explanations everywhere.
- A guide with pages for the goal, controls, objects, echo, power, hints and the
  precise rules, plus progressive hints.
- A scrolling camera, a power console drawer that never covers the room, and a
  pause menu with settings.
- Settings for music volume, SFX volume, mute, reduced motion, an optional CRT
  look and fullscreen. They are saved with your progress.
- Button names follow the last device you used (keys or pad).

### Audio and motion

- Sound effects for moves, power, pads, gates, the elevator, pickups, failures
  and clears are written as Pyxel MML and play on their own channel. The audio
  system also supports music tracks per screen, but this release ships sound
  effects only.
- Movement, the echo, doors, power and pickups are animated. Animation never
  delays input: a new action snaps running animations to their end.
- Reduced motion is available in the settings.

### CRT look

- An optional scanline look, off by default, in the settings.

## Install and run

**Windows.** Run `Echo_Shift-0.1.0-windows-x64-setup.exe`. It installs for
your user only (no administrator prompt) into
`%LOCALAPPDATA%\Programs\Echo Shift`, adds a Start menu shortcut and can be
removed from Settings → Apps. If SmartScreen shows "Windows protected your PC",
click **More info**, then **Run anyway**.

For the portable build, unzip the whole folder (keep `EchoShift.exe` next to
`_internal`) and run `EchoShift.exe`.

**macOS.** Pick the arm64 build for Apple silicon and the x86_64 build for
Intel. Unzip it and move `Echo Shift.app` to Applications. The first launch is
blocked because the app is not notarized: open System Settings, go to Privacy &
Security and click **Open Anyway**, or clear the quarantine flag in a terminal:

```bash
xattr -dr com.apple.quarantine "/Applications/Echo Shift.app"
```

**Linux.** Make the AppImage executable and run it:

```bash
chmod +x Echo_Shift-0.1.0-x86_64.AppImage
./Echo_Shift-0.1.0-x86_64.AppImage
```

The AppImage embeds update information, so AppImageUpdate or AppImageLauncher
can fetch later releases using the `.zsync` file. It needs FUSE (`fusermount`);
without it, run it with `--appimage-extract-and-run`. Alternatively, extract the tar.gz and
run `./echo-shift` from the extracted folder. The Linux builds are made on
Ubuntu 22.04, need glibc 2.35 or newer, and exist for x86_64 only.

## Updating

Saves and settings are kept in the per-user data directory below, never next
to the game, so installing a new version or removing the game keeps your
progress.

- **Windows installer:** run the newer installer. It finds the existing
  install, closes the game if it is running and replaces the old program files.
- **Portable zip, macOS and tar.gz:** delete the old folder or app and unpack
  the new one in its place. Do not unpack a new version over an old folder.
- **AppImage:** update with AppImageUpdate or AppImageLauncher, or download
  the new AppImage.

The game does not check for updates itself.

## Saves and logs

Progress and settings are saved as `progress.json` in the per-user data
directory, next to `startup.log`. Delete `progress.json` to lock all chambers
again.

| Platform | Per-user data directory |
|---|---|
| Windows | `%APPDATA%\EchoShift` |
| Linux and macOS | `$XDG_DATA_HOME/echo-shift`, by default `~/.local/share/echo-shift` |

## Known limitations

- The builds are unsigned, so Windows SmartScreen and macOS Gatekeeper warn on
  first launch (see above).
- On macOS, saves go to `~/.local/share/echo-shift` rather than
  `~/Library/Application Support`.
- The packaged game unpacks itself into the system temp folder on each launch.
- `EchoShift.exe` itself shows the default PyInstaller icon; the installer and
  its shortcuts use the game icon.
- There are no Linux arm64 or Windows arm64 builds.
- The gamepad support uses the first connected pad and ignores the sticks.
